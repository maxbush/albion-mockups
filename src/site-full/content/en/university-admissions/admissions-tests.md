# University Admissions Tests: MAT, PAT, LNAT, UCAT and Others

For a growing number of British programmes, school grades alone do not decide: universities measure candidates on their own tests. Below is the map of the main exams — the exact set depends on the subject and the university's current cycle.

## The main tests by discipline

| Test | Where it is used | What it measures |
|---|---|---|
| **MAT** | mathematics, computer science — Oxford, Imperial, Warwick | mathematical thinking beyond the syllabus |
| **PAT** | physics, engineering — Oxford | physics and maths under time pressure |
| **ESAT** | engineering, natural sciences — Cambridge, Imperial | maths plus sciences, modular format |
| **LNAT** | law — Oxford, UCL, Durham and others | argument and critical reading; the essay links to the personal statement |
| **UCAT** | medicine, dentistry | decision-making, logic, situational judgement |
| **TARA** | a number of programmes — UCL and others | reasoning and academic skills |
| **STEP** | mathematics — Cambridge and others | deep maths papers for conditional offers |

Formats and names change — recently several tests were merged or replaced (NSAA/ENGAA → ESAT and similar). We prepare to the current specification of each university, not to last year's web pages.

## Questions

**When to register?** Registration closes weeks before the test dates — for the autumn Oxbridge cycle, typically September. We control these dates inside the admissions programme.
**Can it be taken abroad?** Most tests run at authorised centres or online — there is no need to travel to Britain.
**What if the score is low?** That is why the university list has a reserve line, and mock testing shows the picture months before the real exam.
