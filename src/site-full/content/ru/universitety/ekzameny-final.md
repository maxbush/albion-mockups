# Вступительные тесты британских вузов: LNAT, TMUA, UCAT, MAT

## Лид

Для конкурентных программ UK экзаменационная рамка — не A-level-оценки, а admissions tests: отдельные тесты, которые отсекают кандидатов до интервью. У каждого — свой формат, свои даты регистрации и своя логика подготовки.

## Карта тестов

| Тест | Для чего | Формат |
|---|---|---|
| **LNAT** | право (Oxford, UCL, LSE и др.) | логика и аргументация + эссе |
| **MAT** | математика/CS, Oxford | предметный, глубокая математика |
| **PAT / ESAT** | физика/инженерия/естественные науки | предметные тесты |
| **TMUA** | математика/экономика (Cambridge и др.) | математическое мышление |
| **UCAT** | медицина/стоматология | аптитудный, скорость и решения |
| **TARA** | гуманитарные/социальные (обновлённая линейка) | академическое мышление |
| **IELTS** | языковое требование всех вузов | Academic |
| **GMAT/GRE** | магистратура/MBA | по требованию программы |

## Что важно знать

- **Регистрация заранее:** у большинства тестов свои окна и дедлайны — пропустить дату регистрации значит потерять год.
- **Форматы меняются:** линейки тестов обновляются (TSA → TARA и др.); готовить надо по актуальным спецификациям, а не по описаниям трёхлетней давности.
- **Тест решает до интервью:** слабый балл закрывает кандидата ещё до того, как комиссия увидит заявку.
