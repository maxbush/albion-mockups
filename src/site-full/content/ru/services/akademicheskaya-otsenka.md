# Академическая оценка: объективная картина ученика

## Лид
Первый шаг любого маршрута — честный ответ на вопрос «где ребёнок сейчас относительно британских сверстников». Не «сильный/слабый», а измеримо: по предметам, по форматам, по конкурсу целевых школ.

## Что входит
- **Тесты прошлых лет** — по реальным экзаменационным форматам целевых школ/вузов.
- **Предметные занятия-диагностики** — тьюторы смотрят живую работу, а не только баллы.
- **Разговор с семьёй** — цели, сроки, ограничения.
- **Письменный отчёт** — уровень по каждому предмету, коридор реалистичных школ/вузов, план подготовки с датами.

## Зачем это перед поступлением
Оценка экономит год: семьи часто целятся не туда — либо занижают планку («просто бы куда-нибудь»), либо называют топ-школы, куда ребёнок не пройдёт конкурс через 6 месяцев — но пройдёт через 18. Разница в сроках, и её видно только по данным.
